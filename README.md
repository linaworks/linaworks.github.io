# linaworks.github.io
A little corner of the internet for ideas, writing, and experiments.

## 双语页面
- 英文沿用原网址 `/`、`/garden/`、`/writing/`、`/projects/`、`/about/`。
- 对应中文放在 `/zh/` 下。语言切换指向同一页面或同一文章，不跳回首页。
- HTML 声明对应语言、独立 canonical、互指 hreflang；站点地图同时收录两种语言。
- 三篇占位笔记继续隐藏，不加入目录或 sitemap。

## 在聊天中发布文章（当前流程）
1. Lina 在聊天中提供中文稿，与助手整理到定稿。
2. 助手生成英文译稿，保留原意、第一人称、事实、来源及未确定的表述，不添加经历或观点。
3. Lina 明确要求发布后，再提交中英文页面，并同步两个语言的首页、文章目录、sitemap 与语言切换链接。
4. 英文之后可以单独润色。必须读取当前线上版本再修改，保留人工修订，禁止用旧译稿覆盖。
5. 中文有实质更新时，对照当前英文同步修改；不要自动重译整篇已润色英文。

不使用翻译 API、密钥或后台自动翻译任务。每次发布由聊天发起。
聚美优品现有英文稿保留不变，新增中文是该稿的对应译文；不要将其标成历史中文原稿。

## 新增一对文章的检查
- 两个语言版本使用相同 slug；导航与返回链接留在当前语言。
- 设置 `lang`、标题、描述、独立 canonical、三项 alternate（en、zh-CN、x-default）。
- 链接 `/assets/bilingual.css`，复制现有语言切换，替换为该文章的两个地址。
- 标题、数字、引用、图表与来源在两个版本间一致；图表要有对应语言和可读的手机版本。
- 检查桌面和手机、所有内部链接与语言来回切换，然后提交并确认 Pages 部署。
